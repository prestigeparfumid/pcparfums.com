# PRESTIGE PARFUM COLLECTION 💎

Tienda online de perfumería de lujo y exclusividad, desarrollada con una arquitectura moderna, segura y lista para producción.

---

## 🚀 Guía de Instalación y Despliegue Paso a Paso

### 1. Requisitos Previos
- Node.js (Versión 18 o superior recomendada).
- Cuenta en Firebase (Auth y Firestore).
- Cuenta en Vercel (Para despliegue y funciones serverless).
- Cuenta en Telegram (Para el bot de notificaciones de pedidos).

### 2. Instalación Local
Clona el repositorio e instala las dependencias:
```bash
git clone <tu-repositorio-url>
cd prestige-parfum-collection
